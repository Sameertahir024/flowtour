🚀 Lightweight Product Tours & Morph Highlights

Guide users effortlessly with fluid spotlight tours

Zero-dependency, customizable product walkthroughs with smooth morphing physics, smart auto-positioning, and instant theme presets.

📖 Read Documentation
⚡

Morph & Glide Physics

Continuous spring transitions with luminous ambient glow that sweeps across any DOM node in path.

🎨

Instant Theming Presets

Built-in support for Dark, Light, Frosted Glass, and Midnight themes with brand accent customization.

⏱️

Custom Speed Control

Full control over animation duration and easing curves globally or per individual step. 

import { createTour } from "flowtour";
import "flowtour/flowtour.css";

const tour = createTour({
  animationStyle: 'morph', // 'morph' | 'glide'
  animationSpeed: 900,     // travel duration in ms
  showProgress: true,
  steps: [
    {
      element: "#search",
      popover: { title: "Search", description: "Find anything in seconds." }
    },
    {
      element: "#notifications",
      popover: { title: "Stay updated", description: "All your alerts live here." }
    },
    {
      element: "#profile",
      popover: { title: "Your account", description: "Manage settings and billing." }
    }
  ]
});

tour.drive();
